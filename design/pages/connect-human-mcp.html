Where to paste it in ChatGPT, on the web. Developer mode can depend on your plan and workspace settings.

  1. Turn on Developer mode

    Open Settings → Security and login and switch on Developer mode.

  2. Add a new plugin

    Go to chatgpt.com/plugins and select +. Name it Human MCP.

  3. Paste the address

    Under Connection, paste the address and select Create.

  4. Sign in, then use it

    Sign in with your Human MCP account when asked. In a new chat, add Human MCP from the + menu.

Where to paste it in Claude, on the web or Claude Desktop. Free plans can add one custom connector. On Team and Enterprise, an owner adds it first in Organization settings → Connectors.

  1. Open Connectors

    Go to Customize → Connectors, select + Add, then Add custom connector.

  2. Paste the address

    Name it Human MCP, paste the address, and select Continue. Leave the sign-in settings as Claude shows them, then select Add.

  3. Sign in once

    Sign in with your Human MCP account when Claude asks.

  4. Turn it on in a chat

    Select + at the bottom left, open Connectors, and switch on Human MCP.
