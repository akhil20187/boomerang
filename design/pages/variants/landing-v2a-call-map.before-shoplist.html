Get started

Live for testing. Shop calling is in early testing, so some calls may not go through yet.

  1. Turn on Developer modeSettings → Security and login → Developer mode.
  2. Add a new pluginGo to chatgpt.com/plugins, select +, name it Boomerang and add a short description.
  3. Paste the addressUnder Connection, paste it and select Create.
  4. Sign in, then use itIn a new chat, add Boomerang from the tools menu.

Needs Developer mode: ChatGPT Business, Enterprise and Edu. On Pro, Boomerang can connect but may not be able to start calls. On Business, your admin may need to turn Developer mode on.

  1. Open ConnectorsGo to Customize → Connectors, then + Add → Add custom connector.
  2. Paste the addressName it Boomerang, paste the address, select Continue, then Continue again.
  3. Choose sign-in, then AddUnder Authentication, choose Sign in now. Under OAuth client, choose Register automatically. Select Add and sign in.
  4. Turn it on in a chat+ → Connectors → switch on Boomerang.

Works on Free, Pro, Max, Team and Enterprise. On Team and Enterprise, an owner adds it under Organization settings → Connectors.
