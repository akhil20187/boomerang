# iPhone store reviews test

Verified on 4 October 2026: Place Details returned 5 reviews for iMagine (Apple Authorised Reseller).

Exact GET request and raw response: [iphone-store-reviews-place-details.json](iphone-store-reviews-place-details.json). API key redacted.

Each review includes rating, comment text, original text, author attribution, publication timestamp, relative publication time, Google Maps link and report-content link. Google returned five selected reviews, not the full history.

## Commercials

India list pricing: Place Details Enterprise + Atmosphere has 7,000 free requests per month, then $7.50 per 1,000 requests. At an illustrative ₹96/$, this is ₹0.72 per single-store request, covering all five returned reviews; not ₹0.72 per review. India pricing eligibility, remaining allowance and actual invoiced charge have not been checked. Taxes and currency conversion may differ.

This test also used one Text Search request to resolve the store ID and fetch reviews: Text Search Enterprise + Atmosphere is $12 per 1,000 after its separate 7,000 monthly free allowance, approximately ₹1.15 per request. Total for both test requests after allowances: $0.0195, approximately ₹1.87. Existing store IDs allow later review fetches to use only Place Details.

Source: [Google India pricing](https://developers.google.com/maps/billing-and-pricing/pricing-india).
